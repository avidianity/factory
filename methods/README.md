# Methods

Methods are reference pages.
They explain why the Kit's rules hold, and give deeper techniques for when a Project needs them.
A Project does not copy them; task pages link here.

| Page | Read it when |
| ---- | ------------ |
| [trust-layers.md](./trust-layers.md) | You decide where a rule should live, or whether a new check is worth it |
| [testing-by-defect-class.md](./testing-by-defect-class.md) | You choose which kind of test to write |
| [formal-methods.md](./formal-methods.md) | A state machine or concurrency bug may need more than tests |
| [failure-injection.md](./failure-injection.md) | You plan adversarial tests for a risk area |
| [threat-model.md](./threat-model.md) | You add a tool, a permission, or an automation for agents |
| [review-prompts.md](./review-prompts.md) | You start an Independent reviewer or an adversarial review |
