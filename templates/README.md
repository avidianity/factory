# Templates

Copy a template, then replace every placeholder in angle brackets.

| Template | Use it for |
| -------- | ---------- |
| [task-contract.md](./task-contract.md) | A task that an agent does alone, in an issue or a Brief |
| [correction.md](./correction.md) | A repeated agent mistake that needs a check |
| [adr.md](./adr.md) | A decision that is hard to reverse |
| [glossary.md](./glossary.md) | A domain glossary |
| [how-to.md](./how-to.md) | A domain's current call contract or topic-guide index |
| [state.md](./state.md) | Current state of a domain (what is live, active limits, integrations) |
| [map.md](./map.md) | System-wide ownership, topology, boundaries, and domain index |
| [feature-map.md](./feature-map.md) | Runtime verification of one user-visible feature |
| [pr-evidence.md](./pr-evidence.md) | The Evidence bundle in a pull request body |
| [risk-summary.md](./risk-summary.md) | A plain-language approval request for the Owner |
| [adoption-plan.md](./adoption-plan.md) | The plan that Bootstrap shows the Owner |
