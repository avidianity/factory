# Adapters

Adapters are the only Kit pages that name specific agents, trackers, or tools.
Every other page uses neutral words, so that the Kit outlives any one tool.

| Page | Covers |
| ---- | ------ |
| [agents.md](./agents.md) | Where each coding agent reads rules, skills, tool servers, and subagents, and how the Owner starts a skill |
| [trackers.md](./trackers.md) | Issue tracker operations for each supported tracker |
| [tools.md](./tools.md) | Isolated checkouts, the skills installer, the JSON compactor, terminal multiplexers, and other helpers |

Facts on these pages change with tool releases.
Each table names the date it was last checked.
Verify a fact against the installed version before you rely on it, as [core/agents/engineering.md](../core/agents/engineering.md#mandatory-external-facts) says.
When a fact is stale, correct this page.

To add an adapter, add a row or a section with the same operations as the existing ones.
